فروشگاه فارسی و RTL واقعی برای WooCommerce، با قالب همراه، فیلتر پویا و جستجوی محصول؛ بدون دادهٔ نمونه.

== Description ==

وردپرس و WooCommerce استاندارد مسئول تمام محصول، تنوع، قیمت، انبار، سفارش، مشتری، سبد، پرداخت و CSV هستند. این افزونه دادهٔ تجاری نمونه، کاربر یا درگاه ساختگی نمی‌سازد.

قالب کامل داخل resources/hamrah-shop-theme.zip است و فقط با اقدام مدیر از صفحهٔ «فروشگاه همراه» به کمک نصب‌کنندهٔ بومی وردپرس نصب/فعال می‌شود. برگه‌های قبلی و دادهٔ واقعی حذف یا بازنویسی نمی‌شوند. انتخاب پرداخت کلاسیک برای سازگاری درگاه‌های ایرانی، برگهٔ جدید ایجاد می‌کند و برگهٔ بلوکی قبلی را حفظ می‌کند.

فیلتر چندانتخابی دسته/برند/ویژگی/قیمت/موجودی/حراج، URL قابل اشتراک، AJAX با fallback واقعی GET، جستجوی نام/SKU/تنوع/طبقه‌بندی/ویژگی، نمایهٔ پس‌زمینه، RTL/موبایل، فونت محلی، علاقه‌مندی مرورگر و خرید فوری بومی.

IRT و IRR قابل انتخاب؛ قیمت‌های ذخیره‌شده با تغییر واحد تبدیل نمی‌شوند. در JSON-LD محصول تومانی، معادل واقعی IRR برای ISO 4217 نمایش داده می‌شود. اعتبارسنجی ایران در checkout کلاسیک و Store API با نرمال‌سازی ارقام فارسی/عربی.

== Installation ==

1. WordPress فارسی و WooCommerce رسمی نسخهٔ ۱۰ یا بالاتر را نصب و فعال کنید؛ از سایت موجود پشتیبان بگیرید.
2. ZIP این بسته را از افزونه‌ها ← افزودن ← بارگذاری افزونه، نصب و فعال کنید.
3. در فروشگاه همراه، نصب و فعال‌سازی قالب و سپس آماده‌سازی برگه‌ها را اجرا کنید.
4. زبان/ترجمه‌ها، واحد پول، نشانی واقعی، ارسال، حساب‌ها و درگاه واقعی را از WP/Woo تنظیم کنید.
5. docs/راهنمای-نصب.html را بخوانید؛ از همان صفحهٔ مدیریت نیز قابل دسترسی است.

== Frequently Asked Questions ==

= اطلاعات نمونه‌ای وجود دارد؟ =
خیر. هیچ محصول، سفارش، مشتری، برند، مقاله، تصویر کالا یا بنر نمونه در این افزونه/قالب نیست. روی سایت تازه، کاتالوگ خالی است. دادهٔ موجود شما محفوظ می‌ماند. نمونه‌های خودِ نصب‌کنندهٔ وردپرس/هاست باید فقط با اطمینان و دستی بررسی شوند.

= حساب مدیریت چیست؟ =
حسابی که خودتان هنگام نصب وردپرس ساخته‌اید؛ ورود از /wp-admin/. این بسته هیچ حساب یا رمز پیش‌فرض ندارد.

= درگاه، ایمیل و ارسال آمادهٔ واقعی است؟ =
مسیرهای اصلی WooCommerce آماده و استاندارد هستند، اما ارائه‌دهنده، کلید، هزینه، قرارداد و تحویل ایمیل باید با تنظیم واقعی خودتان انجام شوند. هیچ خدمت بیرونی جعل یا از قبل فعال نشده است.

= علاقه‌مندی بین دستگاه‌ها همگام می‌شود؟ =
خیر؛ یک فهرست اختیاری واقعی در مرورگر همان دستگاه، تا ۱۰۰ شناسهٔ معتبر، بدون سرویس خارجی است.

= حذف افزونه محصولات را پاک می‌کند؟ =
خیر. حذف دادهٔ اختصاصی هم فقط با انتخاب مدیر انجام می‌شود؛ اطلاعات تجاری و برگه‌ها/قالب پاک نمی‌شوند.
